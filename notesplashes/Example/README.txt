🇪🇸 ESPAÑOL:

1. CREAR O COPIAR noteSplashes.png:
   - Opción A: Crea tu propio spritesheet en un programa de arte
   - Opción B: Copia noteSplashes.png de un mod de FNF existente
   - Formato: PNG con frames de animación en cuadrícula

2. AJUSTAR noteSplashes.xml:
   - Abre el archivo con un editor de texto
   - Modifica los valores x, y, width, height según tu spritesheet
   - Los números deben coincidir con la posición real de cada frame

3. PROBAR EN EL JUEGO:
   - Abre FunkyMakerPlayer
   - Settings → "Note Splash" → ENTER
   - Selecciona "Example"
   - ¡Golpea notas con precisión Sick! para ver tu splash!

NOTA: El archivo splash.json es OPCIONAL. FNF estándar NO lo usa.
      Si copias de un mod FNF existente, solo necesitas PNG + XML.

---

🇬🇧 ENGLISH:

1. CREATE OR COPY noteSplashes.png:
   - Option A: Create your own spritesheet in an art program
   - Option B: Copy noteSplashes.png from an existing FNF mod
   - Format: PNG with animation frames in a grid

2. ADJUST noteSplashes.xml:
   - Open the file with a text editor
   - Modify x, y, width, height values according to your spritesheet
   - Numbers must match the actual position of each frame

3. TEST IN-GAME:
   - Open FunkyMakerPlayer
   - Settings → "Note Splash" → ENTER
   - Select "Example"
   - Hit notes with Sick! accuracy to see your splash!

NOTE: The splash.json file is OPTIONAL. Standard FNF does NOT use it.
      If copying from an existing FNF mod, you only need PNG + XML.

Si tienes un mod de FNF (Psych Engine, Codename, etc.):

1. Busca la carpeta del mod: mods/tu-mod/images/
2. Copia SOLO estos 2 archivos:
   - noteSplashes.png  ← REQUERIDO
   - noteSplashes.xml  ← REQUERIDO
3. Pégalos en esta carpeta (Example) o crea tu propia carpeta
4. ¡Listo! Funciona automáticamente (NO necesitas splash.json)

🇬🇧 ENGLISH:
If you have an FNF mod (Psych Engine, Codename, etc.):
