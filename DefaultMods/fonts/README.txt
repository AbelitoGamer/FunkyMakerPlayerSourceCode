== Funky Maker Player - Custom Fonts / Fuentes personalizadas ==

────────────────────────────────────────────────────────────
ENGLISH
────────────────────────────────────────────────────────────
Put .ttf or .otf font files directly in this folder (not in subfolders).
In the game: Settings > Graphics > Font Style, then pick one.

To use a font every time the game starts, name it main.ttf or main.otf.

"MilkyNice.otf" is the game's default font. If you delete it, the game
puts it back the next time it starts.

────────────────────────────────────────────────────────────
ESPAÑOL
────────────────────────────────────────────────────────────
Pon archivos de fuente .ttf u .otf directamente en esta carpeta (no en subcarpetas).
En el juego: Settings > Graphics > Font Style, y elige una.

Para usar una fuente siempre al iniciar el juego, llamala main.ttf o main.otf.

"MilkyNice.otf" es la fuente por defecto del juego. Si la borras, el juego
la repone la proxima vez que se inicie.
