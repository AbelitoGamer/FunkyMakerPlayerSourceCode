== Funky Maker Player - mods folder / carpeta mods ==

────────────────────────────────────────────────────────────
ENGLISH
────────────────────────────────────────────────────────────
Everything here can be changed by you. Each folder has its own README.

  levels/        your levels: .fnmm, .zip or .rar files, or unpacked
                 level folders. They appear in Freeplay.
  notestyles/    note skins          Settings > Graphics > Note Style
  notesplashes/  hit splashes        Settings > Graphics > Note Splash
  countdowns/    3-2-1-GO packs      Settings > Graphics > Countdown Style
  fonts/         UI fonts            Settings > Graphics > Font Style

The folders named "Default" / "FMM (Default)" (and fonts/MilkyNice.otf)
are what the game uses by default. Use them as examples. If you delete
any of their files, the game puts back the missing ones the next time it
starts. Files you edit are never overwritten.

────────────────────────────────────────────────────────────
ESPAÑOL
────────────────────────────────────────────────────────────
Todo lo de aqui lo puedes cambiar. Cada carpeta tiene su propio README.

  levels/        tus niveles: archivos .fnmm, .zip o .rar, o carpetas
                 de nivel descomprimidas. Salen en Freeplay.
  notestyles/    skins de notas      Settings > Graphics > Note Style
  notesplashes/  splashes            Settings > Graphics > Note Splash
  countdowns/    cuentas atras       Settings > Graphics > Countdown Style
  fonts/         fuentes             Settings > Graphics > Font Style

Las carpetas "Default" / "FMM (Default)" (y fonts/MilkyNice.otf) son lo
que el juego usa por defecto. Usalas como ejemplo. Si borras alguno de
sus archivos, el juego repone los que falten al volver a iniciarse. Los
archivos que edites nunca se sobrescriben.
