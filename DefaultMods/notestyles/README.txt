== Funky Maker Player - Custom Note Skins / Skins de Flechas Personalizadas ==
== Skins de Flechas Personalizadas / Skins de Flechas Personalizadas ==

────────────────────────────────────────────────────────────
ENGLISH
────────────────────────────────────────────────────────────
HOW TO ADD A CUSTOM SKIN:

1. Create a new folder inside "notestyles/" with any name.
   Example: notestyles/MySkin/

2. Put these files inside your skin folder:

   REQUIRED:
   - fmm.png + fmm.xml         (note arrows — Sparrow atlas)
   - notefmm.png + notefmm.xml (receptors — Sparrow atlas)

   ALSO ACCEPTED (FNF Base format):
   - notes.png + notes.xml           (note arrows)
   - noteStrumline.png + noteStrumline.xml (receptors)

   OPTIONAL:
   - NOTE_hold_FMM.png or NOTE_hold_assets.png (hold note texture)

3. The atlas XML must use these frame name prefixes:
   Notes:     noteLeft, noteDown, noteUp, noteRight
   Receptors: staticLeft/Down/Up/Right
              pressLeft/Down/Up/Right
              confirmLeft/Down/Up/Right
              confirmHoldLeft/Down/Up/Right (optional, falls back to confirm)

4. Open the game, go to Settings > Arrows, and select your skin.
   You will see a live preview on the right side.

NOTES:
- The skin is applied immediately when you press ENTER in the Arrows menu.
- Your skin choice is saved and persists between sessions.
- If a skin fails to load, the game falls back to the Default skin.

ESPAÑOL
────────────────────────────────────────────────────────────
COMO AÑADIR UN SKIN PERSONALIZADO:

1. Crea una carpeta nueva dentro de "notestyles/" con cualquier nombre.
   Ejemplo: notestyles/MiSkin/

2. Pon estos archivos dentro de tu carpeta:

   REQUERIDOS:
   - fmm.png + fmm.xml         (flechas — atlas Sparrow)
   - notefmm.png + notefmm.xml (receptores — atlas Sparrow)

   TAMBIEN ACEPTADOS (formato FNF Base):
   - notes.png + notes.xml                 (flechas)
   - noteStrumline.png + noteStrumline.xml (receptores)

   OPCIONAL:
   - NOTE_hold_FMM.png o NOTE_hold_assets.png (textura de holds)

3. El XML del atlas debe usar estos prefijos de nombres:
   Flechas:    noteLeft, noteDown, noteUp, noteRight
   Receptores: staticLeft/Down/Up/Right
               pressLeft/Down/Up/Right
               confirmLeft/Down/Up/Right
               confirmHoldLeft/Down/Up/Right (opcional, usa confirm si no existe)

4. Abre el juego, ve a Settings > Arrows y selecciona tu skin.
   Veras una preview en tiempo real a la derecha.

NOTAS:
- El skin se aplica al instante cuando presionas ENTER en el menu Arrows.
- Tu eleccion se guarda y persiste entre sesiones.
- Si un skin falla al cargar, el juego usa el skin Default.
