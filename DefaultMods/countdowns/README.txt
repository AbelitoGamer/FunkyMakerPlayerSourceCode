== Funky Maker Player - Custom Countdowns / Cuentas atras personalizadas ==

────────────────────────────────────────────────────────────
ENGLISH
────────────────────────────────────────────────────────────
1. Create a folder inside "countdowns/" with any name.
   Example: countdowns/MyCountdown/
2. Put exactly these three images inside it:
   ready.png, set.png, go.png
   (A folder missing any of them is not listed.)
3. In the game: Settings > Graphics > Countdown Style.
   ENTER opens a preview, LEFT/RIGHT cycles packs.
4. Optional sounds, one per beat (.ogg, .wav or .mp3):
   three, two, one, go     (FNF names also work: intro3, intro2,
                            intro1, introGo)
   Example: countdowns/MyCountdown/three.ogg
   A missing sound uses the default pack's one, if it has it.

"Default/" is the game's built-in countdown (images + three/two/one/go
sounds). Use it as an example.
If you edit or delete its files, the game will put back any file
that is missing the next time it starts (your edits are kept).

────────────────────────────────────────────────────────────
ESPAÑOL
────────────────────────────────────────────────────────────
1. Crea una carpeta dentro de "countdowns/" con cualquier nombre.
   Ejemplo: countdowns/MiCuentaAtras/
2. Pon exactamente estas tres imagenes dentro:
   ready.png, set.png, go.png
   (Si falta alguna, la carpeta no aparece.)
3. En el juego: Settings > Graphics > Countdown Style.
   ENTER abre la vista previa, IZQUIERDA/DERECHA cambia de pack.
4. Sonidos opcionales, uno por tiempo (.ogg, .wav o .mp3):
   three, two, one, go     (tambien sirven intro3, intro2, intro1, introGo)
   Si falta un sonido se usa el del pack por defecto, si lo tiene.

"Default/" es la cuenta atras del juego (imagenes + sonidos three/two/
one/go). Usala como ejemplo.
Si editas o borras sus archivos, el juego repone los que falten
la proxima vez que se inicie (tus cambios se conservan).
